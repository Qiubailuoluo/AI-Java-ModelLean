# 数据库连接准备

本轮只调整 pom.xml、application.yml 和运行说明，没有创建 Mapper、Service、Controller。

## 依赖职责

- mybatis-spring-boot-starter 3.0.5：将 MyBatis 整合进 Spring Boot，根据已有 DataSource 创建 SqlSessionFactory 等组件，后续用于执行 Mapper SQL 和映射结果。
- mysql-connector-j：MySQL JDBC 驱动，通过 JDBC 与 MySQL 通信。版本由 Boot 父 POM 管理，本次解析为 9.7.0；驱动版本不要求与服务端 8.0.39 完全相同，本次实际连接已通过。
- starter 间接引入 JDBC 支持和 HikariCP 连接池。连接池复用连接，不必每次请求都从头建立一个连接；本轮暂不调整池大小。
- runtime：当前代码依赖 JDBC 等接口，具体 MySQL 驱动在运行时需要。
- provided（之前的 Lombok）：编译时需要，运行程序不依赖 Lombok 来动态生成 getter。

## 配置逐项说明

```yaml
spring:
  datasource:
    url: jdbc:mysql://127.0.0.1:3306/lab_web_foundation?characterEncoding=UTF-8
    username: ${LAB_DB_USERNAME}
    password: ${LAB_DB_PASSWORD}

mybatis:
  configuration:
    map-underscore-to-camel-case: true
```

- spring.datasource：Spring Boot 数据源配置前缀。
- jdbc:mysql：使用 MySQL JDBC 协议。
- 127.0.0.1:3306：本机 MySQL 地址与端口。
- lab_web_foundation：练习数据库。
- characterEncoding=UTF-8：驱动连接字符编码配置，不会修改表的字符集。
- ${LAB_DB_USERNAME}、${LAB_DB_PASSWORD}：Spring 配置占位符，启动时从环境中读取。本机值在 Obsidian 本地账户笔记中；公共配置不填写实际密码。
- 在当前 PowerShell 中设置 $env:LAB_DB_USERNAME 等，只影响该进程及后续子进程，不修改机器环境变量。每个新终端需自行设置。
- map-underscore-to-camel-case：自动结果映射时，支持 created_at → createdAt。不会自动建表、生成 SQL 或访问接口。

没有配置 driver-class-name，因为 Boot 可以根据 URL 和类路径上的驱动推断。当前不需要 mapper-locations，因为尚未使用 XML Mapper。

## 实际验证

2026-11-10：Maven package 成功。临时验证程序加载实际启动类和配置，以非 Web 方式启动 Spring 上下文，获取 DataSource 连接并只读查询：

```text
DATABASE=lab_web_foundation
APP_USER_ROWS=0
DATASOURCE=HikariDataSource
MYBATIS_MAPPING=true
DATABASE_CONNECTION_VERIFIED
```

已确认 MyBatis 工厂创建、映射配置生效、JDBC 连接成功且数据库正确；验证后关闭上下文与连接池。未启动 HTTP 监听，也未修改业务记录或既有服务配置。
当前没有 Mapper，因此启动时出现 No MyBatis mapper was found 警告，是本阶段预期，后续添加 Mapper 时处理。
打包和启动成功本身不能替代数据库连接验证，连接池可能延迟建立连接。
