## pom.xml

按文件自上而下阅读。空行只用于分隔；闭合标签表示当前 XML 配置块结束。

- `<?xml version="1.0" encoding="UTF-8"?>`：这是 XML 文件，文本编码为 UTF-8。
- `<project ...>`：所有 Maven 项目配置的根元素。
- `xmlns`：声明 Maven POM 的 XML 命名空间，不表示每次构建都需要访问该网址。
- `xmlns:xsi`：给 XML Schema 相关属性声明前缀。
- `xsi:schemaLocation`：提供配置结构的校验规则位置，编辑器可以据此提示合法标签。
- `<modelVersion>4.0.0</modelVersion>`：POM 配置模型版本，不是 Maven 程序版本或 Java 版本。
- `<parent>`：开始声明继承的父 POM。
- `org.springframework.boot`：父 POM 的 groupId，即组织标识。
- `spring-boot-starter-parent`：父 POM 的 artifactId，即构件名称；提供常用依赖版本和构建默认配置。
- `3.5.16`：本项目固定使用的 Spring Boot 父 POM 版本。
- `<relativePath/>`：不尝试通过默认的 ../pom.xml 寻找父 POM，按坐标从 Maven 仓库解析。
- `</parent>`：结束父 POM 声明。
- `com.qiubai.lab`：当前项目的 groupId。
- `web-foundation`：当前项目的 artifactId。
- `0.0.1-SNAPSHOT`：当前项目自身的开发版本；SNAPSHOT 表示快照，不是稳定发布版本。
- `<properties>`：开始声明供构建使用的属性。
- `<java.version>17</java.version>`：配合父 POM 按 Java 17 配置编译；它不会自动安装或切换本机 JDK。
- `</properties>`：结束属性块。
- `<dependencies>`：开始声明本项目使用的依赖。
- `<dependency>`：开始声明一个依赖。
- `org.springframework.boot`：此依赖的组织标识。
- `spring-boot-starter-web`：Web 开发依赖集合，会传递引入 Spring MVC、JSON 处理和默认嵌入式 Tomcat 等依赖。
- 这里没有写依赖 version：由父 POM 提供的依赖管理决定，不是自动使用最新版本。
- `</dependency>`、`</dependencies>`：依次结束该依赖和依赖列表。
- `<build>`：开始配置构建过程。
- `<plugins>`：开始声明构建插件。
- `<plugin>`：开始声明一个插件。
- `org.springframework.boot`：插件的组织标识。
- `spring-boot-maven-plugin`：配合父 POM 的默认执行，把普通 JAR 重新打包为可用 java -jar 启动的 Spring Boot JAR。
- 依赖主要提供程序需要的库，插件主要参与构建或运行任务，两者职责不同。
- 最后各闭合标签依次结束插件、插件列表、构建块和整个项目。

## 启动类 WebFoundationApplication.java

```java
package com.qiubai.lab.web;
```

声明这个类所在的包。src/main/java 是 Maven 默认的 Java 源码根目录，下面的文件路径与包名对应。

```java
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
```

导入两个类型，让下面可以使用短名称；import 本身不会创建对象或启动程序。

```java
@SpringBootApplication
```

标记 Spring Boot 配置入口，组合了配置类、自动配置和组件扫描等能力。默认从这个类所在的包扫描子包，所以后续业务类通常放在 com.qiubai.lab.web 下面。

```java
public class WebFoundationApplication {
```

声明公共类，类名必须与文件名一致。左大括号开始类的代码范围。

```java
public static void main(String[] args) {
```

Java 程序入口：public 允许外部调用，static 表示无需先创建此类对象，void 表示不返回值，String[] args 接收命令行参数。左大括号开始方法体。

```java
SpringApplication.run(WebFoundationApplication.class, args);
```

使用当前类的类型信息和命令行参数启动 Spring 应用，创建应用上下文；在当前 Web 依赖下，会启动嵌入式 Web 服务器。分号结束语句。

最后两个右大括号依次结束 main 方法和类。

## application.yml

```yaml
spring:
  application:
    name: web-foundation

server:
  address: 127.0.0.1
  port: 18080
```

- YAML 通过空格缩进表达层级，不能随意改为 Tab。
- spring 是 Spring 相关配置的顶层键。
- application 是 spring 下的子键。
- name 设置应用名称，完整属性名是 spring.application.name。它不是数据库名。
- server 与 spring 同级，配置嵌入式 Web 服务器。
- address 限制监听本机回环地址，只能从本机访问该地址。
- port 指定 HTTP 监听端口 18080，与 MySQL 的 3306 无关。
- 文件放在 src/main/resources 下，打包时会加入类路径，Spring Boot 默认可以加载。

## 把三者连起来

Maven 读 pom.xml → 编译和打包 → java 执行 main → Spring Boot 读取配置并启动应用 → Tomcat 监听 127.0.0.1:18080。
