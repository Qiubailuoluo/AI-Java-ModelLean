# 学习路线

这是可扩展路线，不是需要一次完成的清单。每阶段只推进一个小项目。

1. Web 基础：HTTP、分层、参数校验、统一响应、全局异常、日志。
2. 数据访问：MySQL、表设计、SQL、事务、分页、数据库连接池。
3. 登录认证：注册、密码哈希、会话、退出、失效与续期。
4. 权限：角色、接口权限、资源归属校验。
5. 对象存储：MinIO 上传、下载、文件元数据、访问控制。
6. 缓存：Redis 读写、TTL、穿透、击穿、雪崩。
7. 性能：慢查询、执行计划、索引、可复现的数据集。
8. 并发：竞态条件、超卖、幂等、乐观锁与悲观锁。
9. 一致性：MySQL 与 Redis 的失败窗口、补偿与一致性边界。
10. 线程池：队列、拒绝策略、异常传播、上下文、优雅停止。
11. 单点登录：多个应用、认证中心、登录和退出链路。
12. 综合：压测、指标、故障注入、回归验证。

之后按实际问题加入消息队列、任务调度、搜索、测试、CI 等主题。

登录认证会拆分为独立阶段和子项目，详见 [[登录认证分阶段路线]]。当前新增/查询用户模块不是登录模块，不提前加入 Redis 或 JWT。

## 模块验收

- 能从请求入口讲到响应返回。
- 能独立实现核心逻辑。
- 有正常请求与失败请求示例。
- 至少复现并分析一个相关问题。
- 写清适用条件、限制和下一步改进。
