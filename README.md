# Backend Lab

Java 后端工程练习库。每个项目可以独立阅读、运行、修改和验证；笔记使用 Obsidian 管理。

## 当前阶段

第一个项目已接通 POST /api/users，包含数据访问、Service接口/实现、请求校验、统一响应和全局异常。成功数据保留；按ID查询已完成并通过13项HTTP验收，见项目03-模块归档.md；登录、Redis、JWT留给后续模块。

- projects/：独立 Maven 练习项目，按需创建。
- infra/：练习专用服务配置；不修改机器上其他项目的配置。
- scripts/：环境检查、启动和停止脚本。
- notes/：Obsidian 笔记库，在 Obsidian 中选择“打开文件夹作为仓库”。
- templates/：项目说明和实验记录模板。

## 工作原则

每次只聚焦一个可验证的问题。每个项目包含启动说明、请求示例、预期结果和练习任务。
先理解并独立实现，再提取公共代码；不要求一开始搭建通用框架。
本地账户记录保存在 notes/90-本地账户/，默认不提交；仓库提交可填写的配置示例。
已关联 origin：git@github.com:Qiubailuoluo/AI-Java-ModelLean.git。用户授权按需创建分支、提交和推送；在完成可运行且已验证的阶段后整理，不按每轮对话推送。首次推送前检查远程状态和提交内容。
